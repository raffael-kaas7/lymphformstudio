1. Datenschutz auf einen Blick

Allgemeine Hinweise

Die folgenden Hinweise geben einen einfachen Überblick darüber, was mit Ihren personenbezogenen Daten passiert, wenn Sie diese Website besuchen. Personenbezogene Daten sind alle Daten, mit denen Sie persönlich identifiziert werden können.

Datenerfassung auf dieser Website

Wer ist verantwortlich für die Datenerfassung auf dieser Website?

Die Datenverarbeitung auf dieser Website erfolgt durch den Websitebetreiber. Die Kontaktdaten finden Sie im Impressum dieser Website.

Wie erfassen wir Ihre Daten?

Diese Website ist eine statische Website. Wir setzen keine Analyse- oder Tracking-Tools ein. Beim Aufruf der Website werden jedoch technisch notwendige Daten durch den Hosting-Anbieter verarbeitet (z. B. IP-Adresse, Datum und Uhrzeit des Abrufs, aufgerufene Seite/Datei, Browsertyp und Betriebssystem). Diese Daten können in Server-Logfiles gespeichert werden.

Diese Website wird über GitHub Pages bereitgestellt (GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA). Weitere Informationen zum Datenschutz bei GitHub finden Sie im GitHub Privacy Statement

Wofür nutzen wir Ihre Daten?

Die technischen Daten (Logfiles) werden ausschließlich zur Sicherstellung des technischen Betriebs der Website verwendet.

Welche Rechte haben Sie bezüglich Ihrer Daten?

Sie haben jederzeit das Recht, unentgeltlich Auskunft über Herkunft, Empfänger und Zweck Ihrer gespeicherten personenbezogenen Daten zu erhalten. Sie haben außerdem ein Recht, die Berichtigung oder Löschung dieser Daten zu verlangen. Wenn Sie eine Einwilligung zur Datenverarbeitung erteilt haben, können Sie diese Einwilligung jederzeit für die Zukunft widerrufen. Außerdem haben Sie das Recht, unter bestimmten Umständen die Einschränkung der Verarbeitung Ihrer personenbezogenen Daten zu verlangen. Des Weiteren steht Ihnen ein Beschwerderecht bei der zuständigen Aufsichtsbehörde zu.

Hierzu sowie zu weiteren Fragen zum Thema Datenschutz können Sie sich jederzeit an uns wenden.

Eine Verarbeitung von Daten in einem Drittland (z. B. USA) kann nicht ausgeschlossen werden. Weitere Informationen zu Art, Umfang und Rechtsgrundlagen der Verarbeitung finden Sie in der Datenschutzerklärung von GitHub (Link oben).

Wenn Sie uns per E-Mail oder Telefon kontaktieren, verarbeiten wir die von Ihnen übermittelten Daten (z. B. Name, Kontaktangaben, Inhalt der Nachricht) zur Bearbeitung Ihrer Anfrage. Rechtsgrundlage ist Art. 6 Abs. 1 lit. b DSGVO (vorvertragliche/vertragliche Kommunikation) oder Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an der Beantwortung von Anfragen).

Wenn Sie uns über WhatsApp kontaktieren (Link auf dieser Website), erfolgt die Kommunikation zusätzlich über den Dienstanbieter WhatsApp (in der EU regelmäßig: WhatsApp Ireland Limited). Dabei werden personenbezogene Daten (z. B. Telefonnummer, Kommunikationsinhalte sowie technische Verbindungsdaten) auch durch WhatsApp verarbeitet. Eine Verarbeitung in Drittländern (z. B. USA) kann nicht ausgeschlossen werden. Weitere Informationen finden Sie in den Datenschutzhinweisen von WhatsApp: https://www.whatsapp.com/legal/privacy-policy

Wir speichern Kommunikationsinhalte grundsätzlich nur so lange, wie dies zur Bearbeitung Ihrer Anfrage erforderlich ist, bzw. solange gesetzliche Aufbewahrungspflichten bestehen.
